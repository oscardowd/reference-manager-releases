Privacy

Reference Manager for Word inserts and formats citations in the document you have open. It has no account, no analytics and no advertising, and it does not send your document anywhere.

What stays on your device

  • Your citations and the copy of each cited reference are stored inside your Word document, as Word stores any other document content.
  • References you add in the pane, and citation styles it has downloaded, are kept in this add-in's own storage on this device so they are there next time. Removing the add-in's data in Word removes them.
  • When the Reference Manager desktop app runs on this computer, the pane talks to it directly on this computer (localhost). Nothing in that exchange leaves your computer.

What the pane sends, and to whom

  • Microsoft (appsforoffice.microsoft.com): Word loads Microsoft's Office.js library for every add-in.
  • The Citation Style Language project, on GitHub (raw.githubusercontent.com): the first time a citation style or language is needed without the desktop app, its file is downloaded. The request names the style file and nothing else.
  • Metadata services, only when you choose Look up and only the identifier you typed: a DOI to Crossref (api.crossref.org) and DataCite (api.datacite.org); a PMID or PMCID to the US National Library of Medicine (eutils.ncbi.nlm.nih.gov); an ISBN to Open Library (openlibrary.org); a clinical-trial number to ClinicalTrials.gov (clinicaltrials.gov).

These requests carry no cookies and no referring page. Each service receives your network address, as any web request does, under its own privacy policy.
