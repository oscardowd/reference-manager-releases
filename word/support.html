Reference Manager for Word

Insert citations, write the bibliography and change citation style in Word on Windows, Mac, iPad and the web.

Two ways the pane works

  • With the Reference Manager app on the same Mac or PC, the pane searches your whole library. The header says Connected.
  • Without it — on iPad, in Word on the web, or when the app is closed — the pane works from the references already cited in the document, plus any you add by DOI, PMID or by hand. The header says This document. Citations, the bibliography and the style can all be updated.

Using it with the desktop app

  1. Install Reference Manager on your Mac or PC from its download page.
  2. In Reference Manager, choose Word › Set Up Word on This Mac (or This PC). It makes a secure connection that only this computer can use, and your computer asks you to allow it.
  3. Quit and reopen Word. Keep Reference Manager open while you cite; the pane's header says Connected.

Common questions

  • A citation style is not available. Without the app, the pane offers the styles in its list. A document written in another style can be updated once the app is open.
  • A style could not be downloaded. Styles are downloaded the first time they are used. Connect to the internet once; after that they work offline.
  • After deleting citations, choose Update document on the Document tab so the bibliography follows.
  • The pane says This document although the app is open. Choose Word › Set Up Word in the app again; if your computer asked you to allow the connection and you declined, setup stops there. Word on the web cannot reach the app in some browsers; the pane then works from the document.
